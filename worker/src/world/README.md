# Playable local world

Admission (`gtasf-nhw`) is HTTP FIFO through `LobbyDO`. `flags.worldCapacity` enables a default 150-player city, configurable with `WORLD_CAPACITY` (1–500). WorldDO counts active peers plus durable reservations atomically; only a single-use grant in the `gtasf.admit.<grant>` WebSocket subprotocol can connect. Waiting visitors keep a two-minute renewable ticket, receive rank plus an ETA only after real departures establish a rate, and never allocate a World socket. Loading reservations last 30 seconds, renewable for at most three minutes. Existing generation-fenced player identities remain independent of the active-player cap.

`LAUNCH_MODE=open|waitlist|invite` gates entry independently of capacity. Invite mode requires an `INVITE_CODE` Wrangler secret; `?invite=...` exchanges it for a signed HttpOnly cookie and removes it from browser history. Missing invite configuration fails closed. `/api/waitlist` saves unique normalized emails to D1 after migration `0006_waitlist.sql`; pending signups send no email, and confirmation/double opt-in delivery is future work. The launch page and queue both expose signup.

Input inactivity expires at five minutes. `ACTIVITY` comes from genuine DOM input and throttled held physical controls (`net.activity()`); PING and periodic MOVE/VEHICLE_MOVE do not reset it. The client shows an explicit rejoin button after idle removal. Reconnects enter FIFO normally; they cannot bypass a full world using a resume token. Internal reservation routes are never forwarded by the public Worker.

One isolated native smoke (`npx vitest run --config worker/src/world/admission.config.ts`) checks invite rejection/cookies, capacity-one FIFO, missing/replayed grants, real socket idle removal, input-vs-heartbeat behavior, reservation expiry and D1 deduplication. It uses a test-only flags alias, leaving the shared preview unchanged.

`WorldDO` owns anonymous v2 sessions, player snapshots, parked-car ownership and robotaxi movement. `flags.driving` and `flags.robotaxi` gate network commands and simulation. Enable them when the game loop mounts the corresponding controls/models.

- New sessions use `localSpawn.ts`. A valid initial WebSocket `spawn=x,y,z,yaw` query overrides the initial/resumed pose once, before WELCOME. Values are integer centimetres and a yaw byte; the client resolves walkable ground first. `connectWorld({spawn})` stops sending this override after its first WELCOME, so reconnects restore the latest pose.
- `VEHICLE_ENTER` requires a free car within 5.5 m. The server broadcasts `VEHICLE_STATE` and sends a local `CORRECTION`. Drivers send `VEHICLE_MOVE`; ordinary `MOVE` is ignored while seated. Rejected driver motion gets a correction. `VEHICLE_EXIT` steps to the driver's side. Disconnects release seats.
- `ROBOTAXI_HAIL` snaps pickup/destination to lanes, computes a directed A* route and spawns about 150 m upstream along connected lane geometry (shorter only when the available incoming graph ends). Ferry and Lombard approach times are roughly 13–15 seconds at actual lane speeds. The taxi approaches, waits for the player within 7 m, boards automatically, drives on the server, and drops the player off at arrival. Cancel and E exit work during a ride. Taxi requests are limited to one per player and at most one new request per two seconds. Duplicate request IDs reuse the existing trip; simultaneous riders receive separate taxis, cannot steer or enter each other's autonomous cars, and disconnect cancels only that rider's trip.
- `VEHICLE_SNAPSHOT` is the recipient's complete visible fleet at 10 Hz; remove missing IDs. Parked/driven/taxi vehicles within 500 m and the recipient's occupied vehicle share one packet with NPC traffic within 400 m. NPC IDs start at 1,000,000 and vehicle flag `0x20` makes them non-enterable. Arrived taxis remain parked for 30 seconds. `ROBOTAXI_STATE` goes to the requester on transitions and once per second. `VEHICLE_STATE` goes to all players. Player pose flags `0x40` and `0x80` mean driver and passenger; their positions remain ground-contact vehicle positions.
- Vehicle kind/model mapping: prius/prius, tesla/model3, subaru/outback, bus/muni-bus, robotaxi/robotaxi, cable-car/powell-cable-car, supercar/vc-supercar. All use +Z forward; yaw radians = byte / 256 * 2π.

`localRoadData.ts` embeds the verified OSM/elevation lane graph from `tools/map/out/lombard/roadgraph-local-play.json`, produced by `tools/map/src/pipeline/local-play.ts`. Geometry is source data: Ferry→Lombard, the full downhill switchbacks, the return to Ferry, and incoming pickup lanes. The Ferry plaza spawn is [1196.869,3.328,-1224.309] m; its curb pickup is [1212.424,3.064,-1236.014], about 20 m away. Guide the player to the taxi at the curb before automatic boarding. Requests outside this route union report unavailable. The local fleet resets when the Worker restarts; player identity and last position remain durable, and resume returns the player on foot. Duplicated tabs that inherit a token rejoin as a second anonymous player rather than remaining disconnected. City-scale traffic, signals, durable fleet storage, and deployment/load acceptance remain separate track-D work.

Local smoke checks: `vitest run worker/src/world/vehicles.test.ts worker/src/world/localRobotaxi.test.ts --maxWorkers=1`. With the playable flags enabled, `vitest run --config worker/src/world/localplay.config.ts --maxWorkers=1` exercises real native Worker sockets, SQLite admission, two-player visibility, car ownership/movement, linked spawn, and hail/cancel dispatch. Worker preview bundle: `npm run build -w worker -- --outdir .wrangler/bootstrap-worker` with Node 24. No property/performance/golden gate is claimed by these checks.

Traffic integration smoke: with `flags.traffic` enabled, `vitest run --config worker/src/world/traffic.config.ts --maxWorkers=1` checks moving nearby NPC snapshots at Ferry and Lombard, per-viewer distance, preserved starter cars and ownership rejection. The local graph retains source `osmNode`, `kind` and `next` metadata to synchronize junction controls and legal turns. The traffic flag gates construction, simulation and publication; the client fleet excludes NPCs from its enter-car prompt.
