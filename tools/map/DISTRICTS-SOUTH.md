# Southern district build-out — gtasf-npnq

Owner: DarkMarsh. Scope: Bernal Heights, Potrero Hill, Bayview, Excelsior,
Glen Park, Noe Valley and Castro. Source configuration only; baked map artifacts
are generated by the deploy/map owner.

## Observed baseline

The city bake outside the original corridor uses a 32 m terrain grid, omits
pavement and collision, drops building footprints smaller than 400 m², and
simplifies surviving buildings by 4 m. This loses the small houses that define
these districts. Both facade shaders also have a broad Mission region that
extends into the southern and western districts.

The five local teleoperator frames were reviewed by eye only (teleop-1 through teleop-5):
continuous light pavements and visible kerbs, dark asphalt, storefront bases,
different facade materials and tree-lined streets. No reference image is copied,
shipped or used as an image-generation input.

## Reproducible checks

Run from the repository root. The wrapper serializes work and applies nice 15.

```sh
tools/heavy.sh npx vitest run --config tools/map/vitest.config.ts tools/map/test/district-south.test.ts --maxWorkers=1
tools/heavy.sh npx tsc --noEmit -p tools/map/tsconfig.json
tools/heavy.sh npx tsx tools/map/south-district-source-smoke.mts
```

The focused fixture exercises all seven registry entries through real building,
ground and pavement pipeline functions. It checks sourced residential/retail/
warehouse types and heights, small-building retention on selected streets,
non-retention on an unconfigured side street, concrete versus asphalt, and
mapped park colour versus urban ground. It does not render the game or prove
kerb visuals; kerbs and furniture are runtime street-detail consumers.

The read-only source smoke hashes the cached manifest, packed city road graph
and arrival terrain, then uses the client road snapper on complete local query
geometry. It checks every configured street against the source graph and makes
sure all seven arrivals select their intended ordinary surface street. The
original candidate coordinates were refined by projection onto those actual
source lanes, not manually moved baked geometry.
